# User Documentation

This folder is for CLI users. It explains how to install NAPE, run evidence collection, inspect outputs, and work through examples.

## Reading Order

1. [Installation](installation.md)
2. [Quickstart](quickstart.md)
3. [CLI workflow](cli-workflow.md)
4. [CLI reference](cli-reference.md)
5. [Procedure authoring](procedure-authoring.md)
6. [Rover Medical example](rover-medical-example.md)

## What Each Document Covers

`installation.md`

How to build or install `nape`, install `nape-eval`, verify both tools, and make the CLI available on `PATH`.

`quickstart.md`

The smallest useful local run: start a collection, collect one evidence file, and generate a report.

`cli-workflow.md`

The three-step workflow, active run state, output layout, and common errors.

`cli-reference.md`

Command arguments, validation rules, examples, and generated outcome values.

`procedure-authoring.md`

How to design activities and actions, write test/evidence paths, validate procedure runs, and avoid common authoring mistakes.

`rover-medical-example.md`

A fuller local example based on the Rover Medical demo repositories.

## What Is Not Here

- File-format reference lives in `../reference/`.
- Maintainer implementation details live in `../maintainers/`.
- Product-level contracts and limitations live in `../product/`.
