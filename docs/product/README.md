# Product Contract

The normative Verification V2 contract is owned by the Attestify Product
Specification, not duplicated in this repository. Current NAPE implementation
contracts are generated read-only into:

```text
contracts/attestify-nape-verification-engine-contract-projection-v2/
```

Run its `verify_projection.py` before relying on the projection. The Product
Specification remains authoritative when prose and a generated projection
disagree.
